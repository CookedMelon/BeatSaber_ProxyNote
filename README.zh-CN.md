# ProxyNote

ProxyNote 是一个用于调整 Beat Saber 方块与炸弹视觉轨迹的模组。插件会创建不带碰撞组件的代理方块，并隐藏原版方块的视觉模型；实际的碰撞检测、切中判定和计分仍由原版方块负责，因此所有调整都只影响显示效果。

与 [BeatSaber_NoteMovementFix](https://github.com/Loloppe/BeatSaber_NoteMovementFix) 直接修改原版方块移动逻辑的实现方式不同，ProxyNote 不会移动或替换用于判定的原版方块。代理方块只负责显示，不参与碰撞与计分，从实现上避免了视觉轨迹调整直接改变判定结果。

插件设置位于选歌界面的 `Mods` → `ProxyNote`。

## 功能说明

### 调整方块旋转

原版方块在接近玩家的过程中会逐渐旋转至最终朝向。通过调整 `方块变向系数`，可以缩小方块初现时与最终朝向之间的角度差：

- `0`：方块从出现开始便保持最终朝向，不再发生转向。
- `1`：完整保留原版的转向幅度。
- `0–1`：按比例保留原版转向效果，默认值为 `0.2`。

### 关闭方块交换

原版轨迹有时会让相邻方块在接近过程中交换位置。关闭 `保留方块交换` 后，方块会直接从最终所在列出现，不再执行横向交换及相应的纵向避让；开启后则保留原版交换轨迹。

### 方块跳跃提前

原版方块会在接近玩家时进入跳跃轨迹。通过调整 `方块跳跃提前（米）`，可以让方块与炸弹在更远处开始跳跃，从而更早看清其最终高度与位置。

该参数可在 `0–5` 米之间调整，`0` 表示使用原版起跳距离。此功能只改变代理方块的视觉轨迹，不会改变音符的实际击打时间与判定位置。

### 显示切割引导

开启 `显示切割引导` 后，带有切割方向的代理方块会显示方向引导，效果与 [BeatSaber_NoteCutGuide](https://github.com/Loloppe/BeatSaber_NoteCutGuide) 类似。引导仅用于显示，不带碰撞效果，并会在方块靠近玩家时自动隐藏，避免遮挡击打。

### PC 视角显示

默认情况下，头显中显示代理方块，PC 画面仍显示原版方块。开启 `PC 视角显示插件效果` 后，PC 画面也会显示与头显相同的代理方块及视觉轨迹。

### 隐藏原版碎块

开启 `隐藏原版碎块` 后，切中方块时不再显示原版方块分裂产生的两半碎块。命中特效、震动反馈和计分不会受到影响。

### 调试模式

开启 `调试模式` 后，会同时显示代理方块与原版轨迹的视觉副本，便于对比两者的位置、旋转和移动过程。开启后可分别调整 `原始方块不透明度` 与 `新方块不透明度`；调试副本同样不带碰撞组件，不会影响游玩判定。

## 使用说明

将发布包中的 `ProxyNote.dll` 放入 Beat Saber 的 `Plugins` 文件夹即可。使用前请确保游戏已安装以下依赖：

- BSIPA
- BeatSaberMarkupLanguage（BSML）
- CameraUtils

目前仅在 Beat Saber `1.40.8` 上完成了构建与实际测试，其他游戏版本尚未验证，无法保证兼容性。
